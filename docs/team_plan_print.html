1. Executive Summary & Core Mission

Unlike reactive post-hoc scam registries (like Chakshu) where victims report after losing money, PhishLens is an active, pre-transaction interception layer. It evaluates messages, URLs, and payment requests across 3 parallel vectors to block scams before the user makes a payment or shares an OTP.

4. The 4-Tier Risk Decision Matrix

Tier Score Action Required Frontend UI Behavior
SAFE 0 – 24 ALLOW Green banner confirmation. Frictionless transaction pass-through.
CAUTION 25 – 49 WARN_USER Amber inline notice. Recommends manual verification of sender.
HIGH_RISK 50 – 77 BLOCK_TRANSACTION Orange persistent alert card. Explicit user confirmation required.
CRITICAL 78 – 100 BLOCK_TRANSACTION Full-Screen Hard Block Modal actively preventing payment or OTP submission.

5. Individual Teammate Action Checklists

👨‍💻 VANSH — Backend Orchestrator & DB Logging
feature/vansh-orchestrator
  • Parallel Dispatch: Implement run_pipeline() in backend/core/orchestrator.py invoking analyze_url(), analyze_sender(), and analyze_intent() concurrently via asyncio.gather().
  • Timeout Supervisor: Enforce asyncio.wait_for(timeout=3.5) for each agent. On timeout or exception, return an ERROR status so the pipeline never hangs.
  • Wire Scoring: Pass the 3 results to Avika's compute_score(req, url_r, sender_r, intent_r).
  • Async SQLite Logger: Create backend/core/db_logger.py using aiosqlite to log scans with PII masking (redacting 10-digit phone numbers and OTPs).
  • Testing: Verify pytest tests/test_pipeline.py -v passes end-to-end.
👨‍💻 ATHARV — URL & Domain Intelligence Agent
feature/atharv-url-agent
  • URL Extraction: Implement analyze_url(req) in backend/agents/url_agent.py. If no URL in text, return status="SKIPPED" with score 0.0.
  • TLD Reputation: Check domain against backend/data/high_risk_tlds.txt (flag .top, .xyz, .club, .cfd → +35 risk).
  • Typosquatting Detection: Compare extracted domain against legitimate banking domains in backend/data/brand_domains.json using Levenshtein distance (e.g., sbi-kyc-verify.top vs onlinesbi.sbi → +50 risk, is_typosquatting=True).
  • Domain Age: Check WHOIS domain age (if age < 30 days → +40 risk).
  • Fail-Safe: Never raise unhandled exceptions; return status="ERROR" on network failures.
👩‍💻 AVNI — Sender Identity & TRAI DLT Agent
feature/avni-sender-agent
  • TRAI DLT Validation: Implement analyze_sender(req) in backend/agents/sender_agent.py. Match sender against Indian commercial header regex ^[A-Z]{2}-[A-Z]{6}$ and verify against certified bank headers in backend/data/trai_dlt_registry.json.
  • Personal GSM Bank Spoofing Rule: If sender is a 10-digit Indian phone number (+91-9...) AND the content claims to be a bank ("SBI", "HDFC", "ICICI", "Income Tax"), assign score 85.0 and flag COMMERCIAL_BANK_CLAIMED_ON_PERSONAL_GSM.
  • Lookalike Headers: Detect unverified alphanumeric headers (e.g. SBI-ALERT).
  • Fail-Safe: Return status="ERROR" on any unexpected failure.
👨‍💻 VIKAS — LLM Psycholinguistic Intent Agent
feature/vikas-intent-agent
  • LLM Inference: Implement analyze_intent(req) in backend/agents/intent_agent.py using Groq LLaMA3 / Gemini Flash with backend/prompts/intent_prompt.txt in deterministic JSON mode.
  • Manipulation Triggers: Detect Panic Urgency ("within 2 hours", "blocked today"), Coercion ("arrest warrant", "police"), and Credential Harvesting ("submit PAN", "verify OTP").
  • Resilient Offline Fallback: If API key is missing or network times out, run local regex keyword heuristics so the pipeline finishes in < 50ms without failing.
👩‍💻 AVIKA — Risk Scoring Engine & Synthesis
feature/avika-scoring-engine
  • Dynamic Weight Normalization: Rebalance weights (URL 40%, Sender 30%, Intent 30%) dynamically if any agent is skipped or errors.
  • Escalation Overrides: Double Whammy (score ≥ 92), GSM Bank Spoofing (score ≥ 88), OTP Harvesting (score ≥ 90), and TRAI Whitelist override (score ≤ 12).
  • Explainable Verdicts: Implement in backend/core/verdict_utils.py and verify via test_scoring.py (< 10ms execution).
👨‍💻 YUVRAJ — Frontend Dashboard & Interception UI
feature/yuvraj-frontend-ui

6. Git PR Review Rules (For All Members)
